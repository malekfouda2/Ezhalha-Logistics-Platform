Pricing

One place to set what clients pay across every shipment type — domestic, international express, and DDP door-to-door.

How pricing works — base rate → markup → minimum → 15% VAT⌄

Local Domestic KSA

carrier base rate
+ markup (% or flat)
floor: min charge
+ 15% VAT
= client price

Express International

live carrier rate
+ profile markup %
(value-tier aware)
+ VAT per scenario
= client price

DDP Door-to-door

billable qty × lane rate
floor: min shipment charge
+ profile DDP markup %
+ margin-only VAT
= client price

Rates come from the carrier APIs where connected; rate-card values are only a fallback. Full reference →
